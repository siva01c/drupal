# Web Application Template

This is a basic Drupal 11 web application template.

## Included Modules

- Core Drupal 11
- Layout Builder (no-code page building)
- Paragraphs (flexible content blocks)
- Simple Sitemap (SEO)
- Metatag (SEO)

## Customization

Edit `config/sync/` to customize:
- Content types
- View modes
- Taxonomy vocabularies
- User roles and permissions
